# Fix binary SEG overlays to follow pixel boundaries

Binary DICOM SEG overlays can cut diagonally through boundary voxels because the existing OpenCV contours follow pixel centres. Thin or isolated voxels can collapse, and union supersampling during volume reslicing can expand the mask.

Trace the exposed edges of foreground pixels at half-integer coordinates and keep the existing vector rendering path. Preserve holes with opposite winding, keep diagonally touching components separate, and simplify only collinear edges. Apply the tracer to binary frame masks, label-map masks, and volume-generated contours. Reslice image planes with one nearest-neighbour sample per output pixel, retaining genuine overlapping labels at the sampled voxel without unioning nearby samples.

## Limitations and follow-ups

- Single-point nearest-neighbour resampling can miss structures smaller than the output grid. Consider a finer temporary reslice grid followed by vector transformation, with explicit resolution and memory limits, rather than restoring union dilation.
- The tracer uses a temporary boxed edge map. Benchmark peak memory, allocation, contour counts, first-display latency, and repaint cost for compact, thin, and fragmented masks; consider compact boundary flags or primitive storage.
- Add rendering tests across zoom levels for outline thickness, highlighting, and filled outlines.
- Separately improve coplanar frame geometry mapping for shifted origins, differing spacing, and rotations when no segmentation volume is available. Geometry lookup is unchanged by this PR.
